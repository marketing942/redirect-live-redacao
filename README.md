# Redirect Live de Redação

Página de captura/redirect para o grupo do WhatsApp da live de redação (sexta-feira, 19h30, Prof.ª Shayenne). Contagem de 5 segundos e redirecionamento para `https://links.cppem.com.br/gp-lv-rd`.

Destino e tempo: constantes `DESTINO` e `SEGUNDOS` no script de `index.html` (e o `<noscript>` e o botão, no mesmo arquivo).

Deploy: Vercel, site estático (raiz do repositório).
